About the Project

ChurnShield — AI Customer Churn Prediction

A machine-learning platform that predicts which customers are likely to cancel their service, scores each one with a confidence probability, and recommends the best retention action.

Technology Stack

Tools and frameworks powering the system
Backend

Python · Flask · REST API serving the trained ML model for real-time inference.

Machine Learning

scikit-learn · pandas · NumPy. Logistic Regression, Random Forest & Gradient Boosting.

Frontend

Bootstrap 5 · Chart.js · Bootstrap Icons · Vanilla JS · Glassmorphism UI.

Visualization

Chart.js for KPIs, gauges, pie/bar/line charts and feature importance.

Dataset

Telco Customer Churn — 7,043 records, 21 features.

Deployment

Flask serves Jinja templates and JSON prediction endpoints.

Machine Learning Workflow

From raw data to deployed predictions
1 · Data Collection

Load the Telco dataset and inspect class balance, missing values and types.

2 · Preprocessing

Impute missing values, encode categoricals, scale numerics, train/test split.

3 · Model Training

Train & compare Logistic Regression, Random Forest and Gradient Boosting.

4 · Evaluation & Deploy

Tune hyperparameters, evaluate accuracy/AUC, serialize model and serve via Flask.
