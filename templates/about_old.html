About This Project

Project Overview

This Customer Churn Prediction System uses Machine Learning to predict whether a telecom customer is likely to leave the company. The system helps businesses identify high-risk customers and improve customer retention.

Technology Stack

  • Python
  • Flask
  • Pandas
  • NumPy
  • Scikit-learn
  • Bootstrap 5
  • HTML
  • CSS
  • JavaScript
  • Chart.js

Dataset

IBM Telco Customer Churn Dataset

Machine Learning Model

Logistic Regression was selected as the best-performing model after comparing multiple machine learning algorithms.
